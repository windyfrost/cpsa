# Contributing

Help improve explanations, verified references, navigation and syllabus coverage. Open an [issue](https://github.com/windyfrost/cpsa/issues) or propose a focused pull request.

## Before editing

1. Read the [coverage tracker](syllabus/README.md) and choose the relevant official skill IDs.
2. Use a feature branch. Keep commits small and explain the learner-facing improvement.
3. Prefer Markdown. Cite primary sources for technical claims; record dates for exam details.
4. Distinguish historical syllabus topics from current operational recommendations.
5. Label original activities clearly; do not represent them as official CREST questions.

## Content and rights

Use only original contributions or material with a documented compatible permission. See the [rights register](resources/licensing-and-attribution.md); no repository-wide license has yet been established. Do not add third-party PDFs, live-exam content, credentials or private evidence. Use publisher links when permissions are uncertain.

Only demonstrate techniques within explicit authorisation. State prerequisites, scope and limitations, and avoid assuming tool output proves a vulnerability.

## Validate your change

- Follow the [validation instructions](docs/maintenance.md#validation).
- Check files, relative links and anchors, including exact case for GitHub.
- Open changed pages in GitHub's Markdown preview before publication.
- For exam changes, check the current CREST guidance and linked technical syllabus.
- For downloads, verify metadata from Releases; never invent asset URLs or editions.

Include sources, checks performed and any unresolved uncertainty in the pull request. Release changes, removal of existing resources, merging and publication need the owner's explicit approval.
