# CREST CPSA Study Hub

A guided collection of study notes, revision references and offline materials for cybersecurity students, aspiring penetration testers and CREST Practitioner Security Analyst (CPSA) candidates.

This is an independent community project, with no CREST endorsement or affiliation. Use the official syllabus as the authority; these notes are a starting point, not complete exam coverage or a passing guarantee.

## Examination overview

CPSA assesses foundational infrastructure and web security assessment knowledge. It is a written, closed-book exam with 120 multiple-choice questions over two hours; the pass mark is 72/120 (60%). No prerequisite certification is required. Delivery is through selected Pearson VUE test centres.

Source: [CREST CPSA guidance](https://www.crest-approved.org/skills-certifications-careers/crest-practitioner-security-analyst/), reviewed 2026-11-10. Check [exam information](docs/exam-information.md) and CREST before booking.

## Learning resources

Begin with [CREST's syllabus](https://www.crest-approved.org/wp-content/uploads/2023/12/CREST-CPSA-Technical-Syllabus-V2.5-.pdf), then choose topic references and hosted labs from [recommended reading](resources/recommended-reading.md). Run tools only in environments where you have permission.
