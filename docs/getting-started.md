# Getting started

[Home](../README.md) · [Study plan](study-plan.md) · [Downloads](downloads.md)

## Your first session

1. Read the [exam summary](exam-information.md) and open the official syllabus linked there.
2. Copy the [coverage tracker](syllabus.md) into your own notes. Mark what you can explain without prompts.
3. Start with assessment management and networking in the [study plan](study-plan.md). If you already know them, demonstrate the checklist outcomes and move on.
4. Pair each reading session with a small permitted lab and a short written explanation of its output.
5. Use [Markdown notes](study-plan.md) online. Use [PDFs](downloads.md) for offline reference, after reviewing the rights notices.

## What you need

A browser and a personal note-taking method are enough to begin. Command practice needs an isolated lab or a training platform with explicit permission; install only the tools needed for the exercise. Keep vulnerable machines isolated from public networks, save snapshots and keep credentials and evidence out of public issues.

## Keep a useful learning log

For each syllabus ID, record a source, your explanation, one piece of lab evidence, an uncertainty and a revisit date. Mark “can explain” only when you can describe both the mechanism and a limitation. There is no fixed preparation time or guaranteed passing route.

Existing PDFs are references, not a complete course. The [audit](audit.md) explains the starting gaps.
