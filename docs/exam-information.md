Use CREST and the booking provider for current prices, identification requirements, accommodations, cancellation rules, validity and retakes. These details can change. The original README's single-choice/multi-select assertion was not verified and is not repeated as an exam rule. Follow the instructions presented in the actual exam.

## Preparation and pacing

Budget roughly one minute per question on average, allowing time to review where the exam interface permits. Practise reading qualifiers and interpreting evidence. Use the official sample questions through CREST; do not collect recalled live-exam content. Tool output interpretation is a useful study exercise, not a prediction of particular exam questions.

## Syllabus caveats

The linked PDF has ten groups A–J. Some CREST webpage summaries omit or mismatch group descriptions; use the technical PDF for the coverage map. Historical technologies remain in v2.5. Learn their security implications while consulting current vendor guidance for real deployments.
