## Primary references

| Topic | Resource | How to use it |
| --- | --- | --- |
| Exam and scope | [Official CREST guidance](https://www.crest-approved.org/skills-certifications-careers/crest-practitioner-security-analyst/) and [syllabus](https://www.crest-approved.org/wp-content/uploads/2023/12/CREST-CPSA-Technical-Syllabus-V2.5-.pdf) | Establish assessed scope and use official samples |
| Scanning | [Nmap reference guide](https://nmap.org/book/man.html) | Check options, states, timing and output |
| Web methodology | [OWASP WSTG](https://owasp.org/www-project-web-security-testing-guide/) | Build a repeatable test method; choose a versioned guide |
| Web concepts and labs | [PortSwigger Academy](https://portswigger.net/web-security) | Pair HTTP reading with introductory hosted exercises |
| Severity | [FIRST CVSS](https://www.first.org/cvss/) | Distinguish version-specific vectors and terminology |
| Ports | [IANA registry](https://www.iana.org/assignments/service-names-port-numbers/service-names-port-numbers.xhtml) | Confirm transport and assigned service names |
| Windows | [Microsoft Windows security documentation](https://learn.microsoft.com/en-us/windows/security/) | Check current identity, policy and platform behaviour |
| Unix | [OpenSSH manuals](https://www.openssh.com/manual.html) and local system manuals | Check SSH and distribution-specific behaviour |
| SQL Server | [Microsoft SQL Server documentation](https://learn.microsoft.com/en-us/sql/sql-server/) | Read about authentication, permissions and patch/version evidence |
| Oracle | [Oracle Database documentation](https://docs.oracle.com/en/database/) | Select the installed version and review security administration |
| Law | [UK legislation](https://www.legislation.gov.uk/) | Read current official texts; historical syllabus references may differ |

## Books and retained references

The original guide recommended *The Web Application Hacker's Handbook*, second edition (Dafydd Stuttard and Marcus Pinto), *Network Security Assessment*, third edition (Chris McNab), and *RTFM* (Ben Clark). CREST's current page also lists Linux and general hacking books. Obtain publisher-authorised or library copies; editions can be dated. Existing repository copies are inventoried in the [catalogue](downloads.md), with [rights concerns](licensing-and-attribution.md).

The [Nmap book website](https://nmap.org/book/) is an author-maintained route to the official book and online chapters.
