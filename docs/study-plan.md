# Study roadmap

[Home](../README.md) · [Coverage tracker](syllabus.md)

This progression develops fundamentals before assessment and application testing. Adapt the pace to your experience; it is not an official CREST timetable.

| Stage | Read | Evidence to produce |
| --- | --- | --- |
| 1 | [Assessment management](assessment-management.md) | Write a one-page scope for your lab, including excluded systems and a stop condition. |
| 2 | [Core skills and networking](networking.md) | Calculate a subnet and explain a saved TCP handshake. Compare encoding, hashing and encryption. |
| 3 | [Information gathering](reconnaissance.md) | Draw a DNS record relationship map for a domain you control. Separate public observations from active requests. |
| 4 | [Vulnerability assessment](vulnerability-assessment.md) | Compare a scanner finding against a lab host inventory, configuration and patch level. Record uncertainty. |
| 5 | [Operating systems and host security](operating-systems.md) | Review a lab file ACL or Unix permission set and trace who can read and modify the file. |
| 6 | [Network and infrastructure security](infrastructure.md) | Review a fictional firewall rule set and a supplied PCAP; identify allowed paths and management exposure. |
| 7 | [Web applications and databases](web-security.md) | Use a hosted training lab to trace login, session state, object access and a database-backed request. |

## Repeatable study cycle

1. Choose a small set of official skill IDs from the [tracker](syllabus.md).
2. Read the corresponding note and a primary source from [recommended reading](recommended-reading.md).
3. Explain the concept without looking at notes; include a common misunderstanding.
4. Perform a scoped exercise from the [lab workflow](practice.md). Save permitted evidence privately.
5. Record gaps, review errors and revisit the topic after a break.

## Revision gate

- [ ] Every A–J group has been reviewed against the official PDF, including the topics absent from these notes.
- [ ] I can interpret addressing, traffic, scan states, permissions and HTTP exchanges.
- [ ] I can distinguish observation from a confirmed finding and propose a mitigation.
- [ ] I have studied cryptography, legacy protocols, Windows/Unix services and database access separately.
- [ ] I have used CREST's official sample questions and reviewed errors without relying on recalled exam material.
- [ ] I have rechecked current booking requirements through [CREST](exam-information.md).

Checking these boxes is a learning aid, not a certification readiness guarantee.
